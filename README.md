## 핵심 원칙

이 앱은 이용자의 **개인건강정보 및 개인 식별 정보를 수집·저장·전송하지 않습니다**.
모든 이용자 입력(증상 일지, 검색, 즐겨찾기, 설정)은 **기기 내부에만 저장**됩니다.
